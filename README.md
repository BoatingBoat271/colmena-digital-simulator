# Colmena Digital Simulator

Plataforma interactiva gamificada para diseñar, simular y cotizar sistemas de seguridad electrónica integrales.

## 🚀 En Construcción

Este proyecto está siendo desarrollado. Pronto tendremos más información.

## 📋 Características Planificadas

- Constructor de planos interactivo
- Simulador de amenazas gamificado
- Sistema de Triple Barrera de Seguridad
- Generador de cotizaciones instantáneas
- Recomendaciones con IA
- Panel Colmena Digital

## 🛠️ Stack Tecnológico

- Next.js 14
- TypeScript
- Tailwind CSS
- shadcn/ui
- Framer Motion
