# Colmena Digital Simulator 🛡️

Plataforma interactiva gamificada para diseñar, simular y cotizar sistemas de seguridad electrónica integrales.

![Landing Page](https://github.com/user-attachments/assets/bab2df35-4c79-4ed5-9996-976dc03f45c8)

## 🚀 Características Principales

### 7 Niveles del Simulador

1. **🧠 Diagnóstico Inteligente** - IA analiza tus necesidades y genera perfil de riesgo
2. **🗺️ Constructor de Planos** - Diseña en 2D/3D con herramientas profesionales *(En desarrollo)*
3. **🛒 Mercado de Tecnologías** - Catálogo completo con Triple Barrera de Seguridad
4. **🎮 Simulador de Amenazas** - Misiones gamificadas contra intrusos, incendios y más
5. **🎛️ Panel Colmena Digital** - Dashboard centralizado de monitoreo 24/7
6. **💰 Presupuesto y Financiamiento** - Cotización instantánea con opciones de leasing
7. **🏆 Comunidad y Logros** - Sistema de puntos, rankings y achievements

### Triple Barrera de Seguridad

#### 🛡️ Barrera 1: Perímetro Inteligente
- Cercos eléctricos certificados
- Sensores de valla/malla
- Barreras infrarrojas y microondas
- Sirenas disuasivas

#### 📹 Barrera 2: Entorno y Operación
- Cámaras IP con IA
- Analítica de video
- Sensores IoT
- Automatización de iluminación

#### 🔐 Barrera 3: Interior y Personas
- Control de acceso biométrico
- Citófonos inteligentes (HIPCAM)
- Botones de pánico
- Detectores de humo IoT

## 🛠️ Stack Tecnológico

- **Framework:** Next.js 14 (App Router)
- **Lenguaje:** TypeScript
- **Estilos:** Tailwind CSS v4
- **Animaciones:** Framer Motion
- **Iconos:** Lucide React
- **State Management:** Zustand
- **Forms:** React Hook Form + Zod

### Preparado para Fase 2:
- **Base de Datos:** Prisma + PostgreSQL
- **Autenticación:** NextAuth.js
- **Editor 2D:** Fabric.js
- **Vista 3D:** React Three Fiber
- **Pagos:** Mercado Pago API

## 📦 Instalación

```bash
# Clonar el repositorio
git clone https://github.com/BoatingBoat271/colmena-digital-simulator.git

# Instalar dependencias
cd colmena-digital-simulator
npm install

# Ejecutar en desarrollo
npm run dev

# Build para producción
npm run build
npm start
```
